# 0077. 中教審と同じ URL の文科省記事を落とし、中教審の 1 件にする

- 状態: 採用
- 日付: 2026-10-06
- 関連 PR: `fix/mext-chukyo-twins`(本 ADR 起票)
- 関連 ADR: [`ADR 0010`](0010-dedupe-skip-existing-id.md)(id での重複排除) / [`ADR 0015`](0015-mext-education-scope-filter-and-data-cleanup.md)(`check-duplicate-links.ts` の導入) / [`ADR 0020`](0020-persistent-article-denylist.md)(denylist)

## 背景

同じ資料が「文科省」と「中教審」の 2 枚のカードで並んでいた(例: 2026-10-05 のアーカイブに `mext_00016.html` が 2 回)。

- `src/lib/sources/chukyo.ts` は `mext.fetch()` の結果を「中央教育審議会|中教審|答申」で絞った派生ソースで、中教審の記事は同じ URL・同じ日付の文科省記事と対になる
- ただし文科省と中教審は RSS を別々に取っていたので、片方だけが失敗する回が、どちらの向きにもあった(2026-04-27 は文科省だけ、2026-09-01 は中教審だけがタイムアウト)。文科省だけが失敗した回に中教審が保存され、次の回で文科省の twin が入った例が 3 件ある。中教審だけが失敗した回に文科省が入る逆向きの経路もあるが、データ上の発生は 0 件
- 記事 id は `<sourceId>-<date>-<sha256(正規化 URL) 先頭 16 桁>`(`src/lib/normalize.ts`)で、頭のソース名だけが違う。`dedupeWithin` / `dedupeAgainstHistory` は id で比べるので落ちない
- 2026-10-06 の main: 2197 件中、114 URL・文科省側の id 115 件。ダイジェストからの参照は 0 件。113 URL は `/b_menu/shingi/chukyo/` 配下で、タイトルは 114 URL すべてで一致

`scripts/check-duplicate-links.ts` はこれまで、この一致を「別媒体扱い」として検出対象から外していた。

## 決定

### D1. 中教審と同じ URL の文科省記事を落とす

- 収集時: `src/lib/dedupe.ts` の `dropMextTwinsOfChukyo` を `scripts/fetch-news.ts` の `dedupeWithin` の直後で通す。同じバッチに同じ `sourceUrl` の chukyo 記事がある mext 記事を落とす
- 残すのは中教審側。より具体的なソースで、URL もその配下にある
- 文科省の RSS は 1 回の収集で 1 度だけ取り、中教審はその結果を絞る(`src/lib/sources/mext.ts` が取得結果を失敗も含めて共有する)。成功も失敗も必ずそろうので、中教審の記事は常に同じバッチで文科省記事と対になり、バッチ内の照合で足りる。履歴との照合はしない
- 代償: 文科省の取得が失敗した回は、中教審も取れない(次の回で入る)。また、その 1 回の失敗が 2 ソースの失敗と数えられ、`fetch-news.ts` の過半数判定(7 ソース中 4 で失敗終了)に早く届く
- 落とすのは mext だけ。他の媒体(nikkyo 等)が同じ資料を報じた記事は別の記事として残す

### D2. 同じソースの出し直しはまとめない

同じソースが同じ URL を日付を変えて出し直したもの(D3 の掃除の前で 114 組、後で 113 組。差の 1 組は文科省の出し直しが中教審と重なっていたもの)は残す(編集者判断、2026-10-06)。114 組中 103 組でタイトルか要約が変わっており(例: 教育新聞が見出しを書き直して 10 日後に出し直す)、内容の更新を伝える価値がある。

### D3. 保存済みデータは一度きりのスクリプトで消し、denylist には足さない

- `scripts/clean-mext-chukyo-twins.ts --expect 115` で、D1 と同じ関数を全期間のデータに当てて消した。件数が `--expect` と合わなければ何も書かずに止まる
- denylist(ADR 0020)には足さない。消した mext 記事がまだ RSS に出ていても、D1 で文科省と中教審の取得がそろうので、同じバッチの chukyo 記事があって D1 が落とし、chukyo 記事は履歴で落ちる

## 影響

- サイト上の文科省のソースページとアーカイブから、中教審と重なっていた 115 件が消える。中教審のページは変わらない
- `check-duplicate-links.ts` の「別媒体扱い」の説明を改めた(検出のキーは変えていない)
- 中教審の語に当たらない文科省の審議会資料は、これまでどおり文科省の記事として残る
