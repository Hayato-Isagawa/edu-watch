# 0089. テーマの切替で OS と同じ色へ戻したら、OS の設定に従う状態へ戻す

- 状態: 採用(0026 の〈localStorage 永続化〉のうち、切替先が OS の設定と同じときを上書き)
- 日付: 2026-11-25
- 関連 issue: #1067
- 関連 ADR: [0026](0026-dark-mode-data-theme-with-system-default.md)
- 姉妹サイト ADR: edu-evidence ADR 0050、edu-law ADR 0038(同じ決定)

## 背景

ADR 0026 は、OS の設定に従うことを既定とし、切替で選んだ値を localStorage に残すと決めた。ただし、消す手段を決めていなかったので、一度でも切り替えると `light` か `dark` が残り続け、OS の設定に従う状態へ二度と戻れなかった。夜だけ暗くしたつもりの人も、その後は OS の設定が無視される。

## 検討した選択肢

- **切替先が OS の設定と同じなら保存を消す(採用)**: ボタンは 2 状態のまま。OS に従う状態と、その反対を固定する状態を行き来する
- **OS の設定が保存した値と同じになったら消す**: 昼夜で OS が自動で切り替わる人は、どちらも固定できなくなる
- **ライト・ダーク・OS に従う、の 3 択**: 意図は明確になるが、ヘッダーに置くには大きく、切替の手数が増える

## 決定

1. 切替を押したとき、切替先が OS の設定と同じなら、保存した値を消す。違えば保存する
2. 判定は押したときだけ行う。OS の設定が変わって保存した値と同じになっても、消さない
3. `e2e/theme-and-focus.spec.ts` が、消えること・消えた後は OS に従うこと・OS が変わっても保存した値が残ることを見る

## 帰結

- OS が昼夜で切り替わる人は、昼に「常にライト」を固定できない(OS がダークの時間帯に切り替えれば固定できる)
- OS に従っているか固定しているかは、見た目からは分からない。従来と同じ
- 前の版で保存された値は残る。OS と違う値なら 1 回、同じ値なら 2 回押すと消える

## 撤回 / 再検討の条件

- 固定できないことで困る声があったとき(3 択を検討する)
