# 0064. 公開後の訂正を changelog で可視化し、書き換えた文の再照合を後段検証ゲートに加える

- 状態: 採用
- 日付: 2026-07-26
- 関連 ADR: [`ADR 0008`](0008-citation-scope-policy.md)(引用範囲遵守ポリシー) / [`ADR 0047`](0047-digest-sections-multi-article.md)(digest sections 構造)
- 関連: [`docs/digest-workflow.md`](../digest-workflow.md)「後段検証ゲート」(PR #332 で導入)

## 背景

2026-07-26 号(PR #437)の公開後、デジタル教科書の意向調査(発行・採択検討会議 第3回 資料4)に関する記述の誤りが、2026-07-19 号と 2026-07-26 号の **2 号にまたがって** 存在することが、原典 PDF のグラフを直接見て判明した。

原典の意向調査は 5 件法「ほぼ紙 / 紙が多い / 半々程度 / デジタルが多い / ほぼデジタル」で集計しており、資料の見出し文は次のように述べている。

- 「小学校低学年・中学年では、全ての教科に渡って、**ほぼ紙か紙の方が多いもの**を望む回答の割合が多い」(①+②の合算)
- 「小学校高学年や中学校では、**デジタルの割合が半分程度以上のもの**を望む回答が多く見られる教科も存在」(③+④+⑤の合算。中点である「半々程度」を含む)

これに対し公開済みの本文は次の 3 型の誤りを含んでいた。

1. **合算区分の取り違え(過大)**: 「低・中学年ではほぼ紙が多数」— 原典が合算している①+②のうち①だけを取り出して「多数」と書いた。
2. **中点の数え込み(過大)**: 「英語や音楽、図画工作・美術ではデジタル寄りが半数を超える」— 原典が集計しているのは「半々程度」を含む区分で、単独区分の最多はその「半々程度」だった。「デジタル寄り」の回答が半数を超えたわけではない。
3. **帰属の取り違え**: 「文科省の意向調査では、紙とデジタルを組み合わせた『融合型』が」— 「融合型」は日本教育新聞の見出しの語であり、文部科学省の資料は「ハイブリッドな形態の教科書」と記している。報道の語を所管庁の資料に帰属させていた。

2 は 2026-07-19 号で発生し、2026-07-26 号でも同型で再発した。**2026-07-26 号の再発は、清書を終えたあとの言い換えで「デジタル寄りでした」という断定が入ったことによる**。この言い換えは公開前の検証を通過している。当時の検証は「検証済みの文字列が最終本文に残っているか」の残存チェックであり、**書き換えた側の文は照合対象に入っていなかった**。

ここに 2 つの欠落がある。

- **公開後の訂正手順が無い**。`docs/digest-workflow.md` は「訂正リスク」に言及するのみで、訂正の可視化方法・判定基準・置き場所を定めていない。今回が初の公開後訂正で型がない。一次情報の正確性がサイト唯一の差別化であるため、誤りを黙って書き換えることは、後から見つかったときに最も損害が大きい。
- **後段検証ゲートに、清書後の書き換えを検証する段が無い**。残存文字列チェックは「落としていないこと」の確認であって、「書き換えた先が正しいこと」の確認ではない。圧縮・言い換えで混入した緩い表現は原理的に検出できない。ADR 0060 以降で整備してきた品質ゲートの、構造的な穴である。

## 決定

### D1. 訂正の可視化を 2 ティアで判定する

- **可視訂正が必須**: 数値・固有名詞・日付・引用・帰属・法令・金額の誤り。および、表現の強弱や帰属の変更で **読者の受け取る事実が変わる** もの。上記 1〜3 はすべてこのティアに入る。
- **静かな修正で可**: 誤字・リンク切れ・体裁・表記ゆれ。changelog にも載せない。

公開からの経過時間・想定読者数は判定に用いない。同日訂正であっても、可視訂正のティアに当たれば可視化する。自ら定めた基準を最初の事例で例外にすると、基準そのものが形骸化するため。

### D2. 可視化は changelog で行う。記事ページに訂正表示は置かない

姉妹サイト edu-evidence の運用に揃える(rule 7)。edu-evidence は数値・効果量・出典帰属の訂正(PISA スコアの取り違え、系統的レビューをメタ分析と表示していた誤り、研究の国の誤記など)を、コラム・戦略ページのいずれについても **changelog の 1 行だけ** で開示してきた。本 ADR の D1 が「可視訂正が必須」とするティアと同じクラスの誤りが、すでにその作法で扱われている。

digest は日付つきのフロー型コンテンツなので記事ページに恒久表示すべき、という設計も検討した。しかし edu-evidence が同じく日付つきのコラム(「日本の少年非行の実像」など)も changelog のみで訂正しており、この区別は成立しない。姉妹サイトで同一クラスの誤りに二つの作法を持つ理由が無いため、記事ページへの訂正表示は採らない。

- **本文は正しい記述に差し替える**。取り消し線で誤りを残す方式は採らない(読み手のコストが増える)。
- 訂正の内容は D3 の changelog 1 行で述べる。**その 1 行は単独で読めるように書く**。記事ページ側に補足が置かれる前提にしない。
- 訂正の頻度が上がる、または 1 行では説明しきれない重大な訂正が生じた場合に、記事ページ表示を再検討する。その時点で edu-evidence と揃えて両サイトに導入する。

### D3. 訂正は changelog に 1 行載せる

rule 8 / 8b に従い、訂正を行う PR の中で `src/pages/changelog.astro` に 1 行追加する(`type: "fix"`)。手段ではなく「何が直ったか」を書く。

D2 により、この 1 行が訂正の唯一の開示先になる。**誤っていた表現と、資料が実際に示している内容の両方**を書く。「訂正しました」だけでは読者が何を信じ直せばよいか分からない。

#### 訂正行の型(以後の標準)

同じ日に複数箇所を直した場合も 1 行にまとめる(rule 8b)。その 1 行は次の 3 点を満たす。

1. **対象** — どの号の、どの話題についての訂正か。
2. **突き合わせた一次資料** — 資料名。必要なら会議名・回次・資料番号まで。
3. **誤っていた表現と、資料が示している内容**。同種の誤りが複数あるときは、全件を逐一書くと行が長くなりかえって読まれないため、**代表 1 件を具体に書き、残りは誤りの類型でまとめてよい**。まとめる場合も**件数は書く**(何件あったかを隠さない)。

**下限**: 「訂正しました」「是正しました」だけで終わる行は認めない。まとめた場合でも、その号を読んだ人が **自分が読んだどの記述を信じ直せばよいか** を判別できること。判別できないなら、まとめ方が粗い。

初回適用(2026-07-26)の実例。帰属の取り違えを具体に書き、集計区分の取り違え 2 件をまとめている。

> 7月19日号・7月26日号のデジタル教科書の意向調査に関する記述を、文部科学省の資料(教科書の発行・採択に関する検討会議 第3回 資料4)と再突合して訂正しました。「融合型」は日本教育新聞の見出しの語だったため資料の「ハイブリッドな形態の教科書」に改め、紙とデジタルの割合に関する2点は原典の集計区分に合わせて是正しています

### D4. 後段検証ゲートに「書き換えた文の再照合」を加える

`docs/digest-workflow.md`「後段検証ゲート」に 2 点を追記する。

1. **清書後に文を書き換えた場合(圧縮・言い換え・分割・結合を含む)、その文は残存文字列チェックでは検証できない**。書き換えた文はその形のまま原典に当て直す。
2. **グラフ・図の数値は PDF を直読する**。`pdftotext` は棒グラフ・円グラフの凡例と数値の対応を壊す。加えて、グラフに数値が印字されていない場合、目測で読んだ割合は本文に書かない。原典の見出し文・注記が言語で述べている範囲にとどめる。

本 ADR の中核はここにある。D1〜D3 は誤りが出た後の作法であり、D4 は誤りの発生源を塞ぐ。

### D5. 既存号の遡及監査は本 ADR のスコープ外

手順を定めることが本 ADR の目的。公開済み全号の洗い直しは、文体の是正と合わせて別 PR で行う。

## 帰結

- 2026-07-19 号・2026-07-26 号の本文を差し替え、訂正の内容は changelog の 1 行に集約した。コレクションスキーマ・詳細ページのテンプレートには手を入れていない。
- 記事ページに訂正表示を置かないため、公開済みの号を読んでいる人は訂正に気づかない。訂正を追うには changelog を見る必要がある。この発見の非対称性は D2 で受け入れたコストであり、edu-evidence も同じコストを負っている。訂正の頻度・重大度が上がった時点で再検討する。
- 訂正の判定に「読者の受け取る事実が変わるか」という主観の入る基準を置いた。誤字と数値誤りの中間(語調の強弱・並列の粒度)は判断が割れうる。運用の実例が溜まった時点で基準を具体化する余地を残す。今回、「算数・数学では紙を残したい意向が強い」(紙寄りは過半だが国語・書写より低い)は **誤りではなく強弱の粒度の問題** として訂正対象から外した。誤りでないものを訂正として開示すると、訂正の重みが薄まるため。
- D4 の「目測の割合を本文に書かない」は、書ける内容を狭める制約になる。グラフから読める傾向を数値で語れなくなるが、原典が言語で述べている範囲は要約せずに使えるため、実務上の損失は小さいと判断した。
- `src/data/articles/*.json` に残る報道見出しの「融合型」は編集しない。ADR 0008 の引用要件「タイトル改変なし」に反するため。本文と収集データで語が異なる状態は意図的なもの。
