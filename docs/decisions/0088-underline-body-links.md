# 0088. 本文のリンクは平常時も下線で示す(edu-evidence ADR 0049 ミラー)

- 状態: 採用
- 日付: 2026-11-24
- 関連 ADR: edu-evidence 0049(原本。選択肢の比較と撤回の条件)、[ADR 0026](0026-dark-mode-data-theme-with-system-default.md)、[ADR 0070](0070-print-stylesheet.md)

## 背景

本文のリンク(`.prose-digest a` と `.link-underline`)は、下線をホバーしたときだけ出していた。平常時の手掛かりは色だけで、アクセント色と本文色の比は実測で light 1.87:1、dark 1.71:1 だった。`global.css` のレイヤ外の `a { color: inherit; … }` が Tailwind の色のユーティリティに勝つため、`text-accent` を書いても地の文と同じ色になるリンクもあった。`0ea87c8` のビルドを走査すると、地の文の中のリンク 168 本(291 ページ)のすべてに平常時の下線が無かった。

## 決定

1. レイヤ外の `a {}` を消す
2. ダイジェストの本文と、`main` の段落・定義・図の説明・引用の中と箇条書きの直下の `.link-underline` と、アクセント色を指定した `.link-underline` に、平常時も実線の下線とアクセント色を付ける。ナビ・見出し・記事のヘッダー・フッター・カードの題名と、太字の一覧(アーカイブの日付など)は対象外。段落の中に置いた「← 一覧」は対象に入る(ダイジェストは記事のヘッダーの中にあるので入らない)
3. 画面だけに効かせる(`@media screen`)。印刷は ADR 0070 の黒の下線に任せる
4. 平常時の線は 1px で、文字の色の 70%。背景との比は両テーマで 3:1 以上を保つ。線は `border-bottom` で描く。ホバーとフォーカスではこの線を消してから、2px の線を左端から右へ引く(動きを減らす設定では動かさない)。どちらも border の箱の下端に置く
5. `e2e/links-and-theme.spec.ts` が、代表ページの地の文のリンクに下線があり色が地の文と違うこと、線の比と引き直しを見る

## 帰結

- 引用の多いダイジェストの印象が変わる
- `text-decoration` の下線と背景の線では、位置の基準(文字のベースラインと箱の下端)が違い、フォントごとにずれる。border と背景なら同じ箱なのでそろう
- 分類の札など、`a` に付けた色のユーティリティが class に書いたとおりになる
