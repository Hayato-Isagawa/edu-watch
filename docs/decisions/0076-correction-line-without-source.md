# 0076. 原典が出ないまま持ち越した claim を直すとき、changelog 行の書き方を読み替える

- 状態: 採用(0064 の D2「本文は正しい記述に差し替える」と、D3 のうち changelog 行に書く内容〈D3 本文第 2 段落と「訂正行の型」の項目 2・3〉を、この場合に限って上書き)
- 日付: 2026-10-06
- 関連 PR: #822(持ち越しの仕組み) / `docs/adr-0076-unpublished-source-correction`(本 ADR 起票)
- 関連 issue: #821 / #823
- 関連 ADR: [`ADR 0064`](0064-post-publication-correction-policy.md)(公開後の訂正) / [`ADR 0058`](0058-unify-changelog-register-and-granularity.md)(changelog の文体と粒度)
- 関連: [`docs/digest-workflow.md`](../digest-workflow.md)「後段検証ゲート」の「持ち越した claim の後始末」

## 背景

後段検証ゲートで原典に当たれなかった claim は、編集者の判断で、公開後に当て直す前提で持ち越せる(#820)。その後始末は #822 で定めた。`publishedAt` から 4 週たっても原典が出なければ、編集者が据え置くか直すかを決める。

直すと決めた場合、0064 のとおりには直せない。D2 は本文を「正しい記述に差し替える」ことを求める。D3 本文第 2 段落は「誤っていた表現と、資料が実際に示している内容の両方」を求める。「訂正行の型」も、項目 2 に「突き合わせた一次資料」、項目 3 に「誤っていた表現と、資料が示している内容」を求める。突き合わせる原典がまだ無く、直す対象も誤りだと確かめられたわけではない。

## 決定

### D1. 適用範囲

- `docs/digest-workflow.md`「持ち越した claim の後始末」の打ち切りで、編集者が直すと決めた場合に限る。原典が出て食い違った場合は、0064 D3 をそのまま使う。
- changelog に載せるかどうかは、0064 D1 の判定(読者の受け取る事実が変わるか)に従う。
- `type: "fix"` も 0064 D3 のまま。fix は changelog 上で「修正」と表示され、誤りだったとは名乗らない。

### D2. changelog の 1 行の書き方

読者向けの 1 行だけが対象。

1. **対象** — 0064 D3 の項目 1 のまま。
2. **依拠した資料と、原典が公開されていないこと** — 項目 2「突き合わせた一次資料」の代わりに書く。
3. **直す前と後の表現** — 項目 3 と D3 本文第 2 段落の代わりに書く。

「誤っていた」「訂正しました」とは書かない。誤りだと確かめられていないため。同じ日に複数の claim を直すときのまとめ方(代表 1 件を具体に書き、件数は書く)は、0064 D3 の項目 3 に従う。下限は 0064 D3 と同じで、その号を読んだ人が、自分が読んだどの記述を信じ直せばよいかを判別できること。

### D3. 直した後の本文

0064 D2 の「本文は正しい記述に差し替える」は、原典が無いので満たせない。直した後の文は、依拠した資料(報道など)に明示的に帰属させるか、claim を削るかのどちらかにする。

## 帰結

- 0064 は、誤りでないものを訂正として開示すると訂正の重みが薄まるとして、強弱の粒度の問題を訂正対象から外した。本 ADR の行も changelog に載るが、誤りとは呼ばず、直す前と後の表現を示して訂正と区別する。
- 本 ADR の書き方を初めて使った回に、その 1 行を実例として本 ADR の `## 更新` 節に足す。

## 検討した選択肢

- **0064 に `## 更新` 節だけを足す**: 採らない。[`README.md`](README.md) の運用方針は、決定の一部を上書きする場合も新しい ADR を起こすよう求めている。
